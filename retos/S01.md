## Lab 1 · Corre y mide (20 min, individual)

| | ☕ Java (`java-selenium/`) | 🎭 Playwright (`ts-playwright/`) |
|---|---|---|
| Unit | `mvn test -Dgroups=unit` | `npm run test:unit` |
| API | `mvn test -Dgroups=api` | `npm run test:api` |
| UI | `mvn test -Dgroups=ui` | `npm run test:ui` |

Cómo leer el tiempo:
- **Java:** el *Time elapsed* de cada clase en la salida de Surefire, dividido entre el número de pruebas.
- **Playwright:** el valor entre paréntesis al lado de cada prueba.

## Lab 1b · Siembra un bug (10 min)

1. Cambia **una línea**:
   - Java: en `PriceCalculator.java`, `RoundingMode.HALF_UP` → `RoundingMode.DOWN`
   - Playwright: en `src/price-calculator.ts`, `Math.round` → `Math.floor` (línea marcada `LÍNEA DEL LAB`)
2. **Antes de correr**, vota: ¿qué capas fallarán?
3. Corre las tres capas y anota.
4. **Revierte el cambio** y confirma que todo vuelve a verde.
